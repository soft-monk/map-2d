## 3. 一分钟了解这个模块

```
map-2d/                     独立可交付的二维地图模块（只依赖 maplibre-gl / react / zustand）
├─ doc/                     ← 本目录：模块需求 + 设计
├─ src/
│  ├─ index.ts              唯一公开入口（嵌入方只从这里 import）
│  ├─ core/                 契约类型 / 模块开关 / 视角命令 / UI 状态 / 实例单例
│  ├─ primitives/api.ts     绘制 API：MapDraw（9 类图元）
│  ├─ render/               图层与数据源管理（10 个图层分组）
│  ├─ ui/                   MapView（唯一渲染入口）/ 工具条 / 图层面板 / 指北针
│  └─ standalone/           独立宿主：npm run dev 打开即出图，不依赖后端
└─ README.md                快速上手与公开 API
```

两条使用方式：

| 方式 | 命令 / 代码 | 说明 |
|---|---|---|
| 独立运行（演示、交付、调试） | `npm install && npm run dev` → `http://localhost:5180/` | 不依赖任何后端，自带示例图元 |
| 嵌入宿主（主系统即此种） | `import { MapView, MapDraw } from '@map2d'` | 数据经 props 注入，模块不读宿主 store |

## 4. 快速状态摘要（详见《需求文档》§4 需求追踪）

**已实现（P1 基线）**

| 域 | 条目 | 实现位置 |
|---|---|---|
| 地图能力 | 拖拽平移、光标为中心缩放、二维锁定、视角命令、视口回写 | `ui/MapView.tsx`、`core/commands.ts` |
| 底图 | 本地栅格瓦片、在线样式、无瓦片兜底、缺口地面色、运行中切换不丢图元 | `ui/MapView.tsx` |
| 图层与图元 | 10 组独立开关、数据驱动渲染、增量更新、脉冲动画 | `render/LayerManager.ts` |
| 绘制接口 | 增删改查、快照导入导出、公里转像素、样式覆盖、底图切换重放 | `primitives/api.ts` |
| 模块 UI | 工具条（选择/图层/清屏/全屏）、图层面板、显示模式徽标 | `ui/`、`core/` |
| 交付 | 独立宿主、类型检查与构建、子仓发布 | `src/standalone/`、`package.json` |

**待开发（P2）**

| 需求 | 内容 | 来源 |
|---|---|---|
| M2-CTRL-01 ~ 05 | **控件按需显示**：指北针、鼠标经纬度、缩放按钮、比例尺默认隐藏，调用接口才显示（经纬度显示为新增） | 需求补充 1 |
