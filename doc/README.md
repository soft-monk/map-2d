## 3. 一分钟了解这个模块

```
map-2d/                     独立可交付的二维地图模块（只依赖 maplibre-gl / react / zustand）
├─ doc/                     ← 本目录：模块需求 + 设计
├─ src/
│  ├─ index.ts              唯一公开入口（嵌入方只从这里 import）
│  ├─ core/                 契约类型 / 模块开关 / 视角命令 / UI 状态 / 实例单例
│  ├─ primitives/api.ts     绘制 API：MapDraw（9 类图元）
│  ├─ render/               图层与数据源管理（10 个图层分组）
│  ├─ ui/                   MapView（唯一渲染入口）/ 工具条 / 图层面板 / 指北针
│  └─ standalone/           独立宿主：npm run dev 打开即出图，不依赖后端
└─ README.md                快速上手与公开 API
```

两条使用方式：

| 方式 | 命令 / 代码 | 说明 |
|---|---|---|
| 独立运行（演示、交付、调试） | `npm install && npm run dev` → `http://localhost:5180/` | 不依赖任何后端，自带示例图元 |
| 嵌入宿主（主系统即此种） | `import { MapView, MapDraw } from '@map2d'` | 数据经 props 注入，模块不读宿主 store |

## 4. 快速状态摘要（详见《需求文档》）

**已有功能**

| 能力 | 实现位置 |
|---|---|
| 二维漫游：拖拽平移 / 滚轮·双击·按钮缩放 / 比例尺 / 指北针 / 禁旋转 | `ui/MapView.tsx`、`ui/Compass.tsx` |
| 底图：本地栅格瓦片 / 在线样式 / 无瓦片兜底 / 运行中切换且不丢图元 | `ui/MapView.tsx` |
| 绘制 API：9 类图元的增删改查、导入导出、公里转像素 | `primitives/api.ts` |
| 图层：10 个分组独立开关、增量更新、脉冲动画 | `render/LayerManager.ts` |
| 模块 UI：工具条（选择/图层/清屏/全屏）、图层面板、显示模式徽标、视角命令 | `ui/`、`core/` |
| 独立运行与交付：不依赖后端的演示宿主、打包与子仓发布 | `src/standalone/`、`package.json` |

**目的功能（尚未实现）**

| 功能 | 状态 |
|---|---|
| 手绘交互：测距 / 区域绘制 / 新建 / 标绘 | 工具为占位，待排期 |
| 显示模式手动切换 | 当前仅随场景+阶段自动展示 |
| 热力图 / 预测轨迹 / 覆盖边界 / 地图内图例 | 待排期 |
| 底图加载观感优化（缩放/拖拽时的深蓝方块） | 已定位成因，曾试一版体感变卡顿已回退 |
| 多实例地图 / npm 包发布 / 瓦片层级扩展 | 长期项 |
