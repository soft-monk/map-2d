## 1. 模块概述

### 1.1 定位

本模块是**二维地图能力的基座**：其他模块（本项目主系统的界面层，或任何第三方项目）不需要了解 MapLibre，只看《接口文档》就能把地图用起来——注入数据、调用接口，其余由本模块负责。

**设计原则（本模块的唯一目标就是把自身做到最好）**

| 原则 | 含义 |
|---|---|
| **性能优先** | 渲染性能与响应速度是首要指标；凡能提升性能的做法（图层/数据源策略、增量更新、缓存、懒加载、批次提交）都可采用，不因"改动大"而回避 |
| **接口完备** | 能力一律接口化：能被调用、能被查询、能被配置、能被关闭。凡是宿主可能需要的控制点，都必须有接口，而不是写死在内部 |
| **文档先行** | 交付物包含《接口文档》：看文档即可接入，无需读源码 |
| **独立自洽** | 模块不依赖任何业务后端代码；地图数据（瓦片）来源由宿主配置（本地服务或在线源），模块只按配置请求 |
| **不夹带业务** | 不含业务逻辑、界面框架、数据获取 |

### 1.2 运行形态

| 形态 | 方式 | 说明 |
|---|---|---|
| 独立运行 | `npm run dev` → `http://localhost:5180/` | **模块自带的演示宿主**：自带示例图元、零业务后端依赖。用途是演示、调试、交付验证与性能基线测量；它的底图瓦片仍由配置指向（本地瓦片服务或在线源），指向的服务不可用时回落纯色底 |
| 嵌入宿主 | `import { MapView, MapDraw } from '@map2d'` | 数据经 props 注入；宿主不出现 source/layer/样式概念 |

## 3. 验收准则

**功能验收**

1. 独立运行 `npm run dev` 打开即出图，无需任何后端；
2. 地图漫游、缩放、二维锁定、视角命令均按 M2-MAP 各条通过；
3. **默认状态下不显示任何地图控件**；按 M2-CTRL-01 / M2-API-05 逐个开启后，指北针、经纬度、缩放按钮、比例尺分别正确出现并可关闭（需求补充 1）；
4. 10 个图层分组可独立开关，状态跨底图切换保留；
5. 绘制接口覆盖 M2-DRAW-01 清单中的全部对象，且每个图元可按 M2-DRAW-03 单独显隐（需求补充 2）；
6. 按 M2-BASE-05 / M2-API-06 设定瓦片精度上限后，放大到更细层级不再请求新瓦片（需求补充 3）；
7. **多底图切换**：声明"卫星影像 + 本地路网"两套底图后，可通过 M2-API-11 任意互切，切换后视角、图元、图层开关、控件开关全部保持，且宿主通过 M2-API-12 收到通知（M2-BASE-09 ~ 12）；
8. 量算、图元编辑、图元事件、聚合与标签避让在容量指标（M2-NFR-07）内均可用。

**接口验收**

1. 宿主代码中不出现 `maplibre-gl` 的直接调用与模块内部路径；
2. 宿主传入的数据对象缺字段时不报错、按约定降级；
3. 导出/导入图元快照后画面一致；视图状态导出/恢复后画面一致。

**性能与可靠性验收**

1. 达到 M2-NFR-07 容量指标时帧率 ≥30 fps（须提供 M2-CTRL-15 的观测数据佐证）；
2. 注入非法图元数据后，其余图元正常渲染（M2-NFR-10）；
3. 断开局域网瓦片后地图仍可打开与交互（M2-BASE-03 / M2-MAP-11）。

**交付验收**

1. `npm run typecheck`、`npm run build` 通过；
2. 模块目录可直接拷贝到新项目运行；
3. 独立子仓可 clone 后 `npm install && npm run dev` 出图。
