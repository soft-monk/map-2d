# map-2d · 验收台使用说明

- 版本：v1.0
- 日期：2026-09-12
- 定位：**用点按钮的方式查看需求完成情况**，不需要读代码、不需要连接后端业务系统

---

## 一、怎么打开

```bat
cd /d <你的路径>\mapApp\map-2d
npm run dev:host          :: 局域网内其他电脑/平板也能访问
```

浏览器打开：**http://localhost:5180/**（或 `http://<本机IP>:5180/`）

前提：瓦片已放在 `map-2d/tiles/raster/...`（详见 [../README.md](../README.md) 第二节）。
没放也能打开，只是底图为空。

## 二、界面上有什么

```
┌──────────────────────────────────────────────────────────────┬───────────────────┐
│ 顶栏：底图下拉 | 载入示例 | 清空 | 图层 | 清屏 | 复位 | 控件勾选 │  功能验收台        │
│                                                              │  ├ 实时指标        │
│                                                              │  ├ ✅ 已实现（可点）│
│                    地  图                                    │  ├ ⏳ 待完成（只读）│
│                                                              │  └ 操作结果 / 事件  │
└──────────────────────────────────────────────────────────────┴───────────────────┘
```

**右侧"功能验收台"** 分四块：

| 区块 | 内容 |
|---|---|
| 实时指标 | 帧率 / 瓦片缓存数 / 最近一次提交耗时 / JS 堆 / 各类图元数量（每秒自动刷新） |
| ✅ 已实现 | 按能力分组，每行 = 一个按钮 + "点了会看到什么"的说明 |
| ⏳ 待完成 | 6 个域、35 条，按需求文档 §6 展示（只读，供对照） |
| 操作结果 / 事件 | 每次点按钮的实际返回值、计数、错误上报；订阅图元点击后这里显示命中的图元 |

## 三、逐个按钮验什么

### 漫游与视角

| 按钮 | 应当看到 |
|---|---|
| 飞回北京 z12 | 视角有过渡动画移回北京；此后拖拽/滚轮/双击都可用；**怎么拖都不会旋转**（二维锁定） |
| 定位到目标 001 | 镜头飞到该目标并放大到 z14 |

### 控件按需显示（需求补充 1）

| 按钮 | 应当看到 |
|---|---|
| 开启全部控件 | 指北针（右侧）、鼠标经纬度（左下）、缩放按钮（右上）、比例尺（左下）**同时出现** |
| 关闭全部控件 | 四类控件立即消失 —— **默认状态就是不显示**，这是设计如此 |

> 顶栏那排「控件：☐指北针 ☐经纬度 ☐缩放按钮 ☐比例尺」是同一套开关的另一种入口（勾选框默认全不勾）。
> 移动鼠标到地图上，经纬度控件会实时刷新。

### 图层分组

| 按钮 | 应当看到 |
|---|---|
| 打开图层面板 | 11 个分组（任务区域/集群编组/无人机/目标/链路/扫描/轨迹/尾迹/脉冲/标注/航线图形区）逐个可开关 |

> 试一试：关掉"目标/锁定框"，再点底图下拉切一下底图 —— 开关状态会被保留（`applyVisibility` 生效）。

### 图元（11 类）

| 按钮 | 应当看到 |
|---|---|
| 只画目标 | 只剩 3 个目标点 |
| 只画航线 | 两条虚线航线（青=侦察航线、琥珀=巡逻航线） |
| 只画圆形/椭圆/目标区 | 蓝色圆（4 km）、紫色椭圆（9×4 km，长轴 35°）、红色目标区、黄虚线搜索区 |
| 只画扫描与脉冲 | 扫描覆盖圈 + 目标外围的扩散脉冲动画 |
| 载入全部示例 | 11 类图元同时出现 |

### 图元显隐 / 批量提交

| 按钮 | 应当看到 |
|---|---|
| 隐藏目标 001 | 该目标消失；日志里写明"数据仍有 3 条、可见性 false"——**隐藏不等于删除** |
| 恢复显示 | 目标 001 重新出现 |
| 批量加 2000 个点 | 日志显示批量提交耗时与"渲染类型 1 类"——2000 个点只渲染一帧 |

### 瓦片精度（需求补充 3）

| 按钮 | 应当看到 |
|---|---|
| 限制到 1km/像素 | 日志显示"精度上限 → maxZoom=7；源 maxzoom=7"；此后**继续放大不再请求更细瓦片**（画面为放大显示） |
| 取消精度限制 | 源 maxzoom 恢复 14 |

### 底图管理（需求补充 4）

| 按钮 | 应当看到 |
|---|---|
| 切到「路网」底图 | **整幅底图替换**；没自备 `tiles/road` 时是缺口底色，但**视角、图元、图层开关、控件开关全部保持** |
| 切回「卫星影像」 | 整幅换回影像 |
| 切不存在的底图 | 日志显示可读失败原因，**当前底图不变、不报异常** |

### 图元事件 / 错误边界 / 运行指标

| 按钮 | 应当看到 |
|---|---|
| 订阅点击（看提示） | 左上出现"订阅中"提示；此后点地图上任意图元，右侧日志出现 `点击命中 → target:T-1` 这类记录；**点空白没有反应** |
| 注入 3 条脏数据 | 日志逐条列出被跳过的脏数据与原因（缺坐标 / 半径非法）；**其余图元照常显示** |
| 刷新指标 | 右侧指标立即刷新（本来也每秒自动刷新） |

### 位图图标与轨迹线宽（本批新增）

| 按钮 | 应当看到 |
|---|---|
| 位图图标 + 线宽 | 4 架无人机分三种画法：光电=**PNG 位图**（`public/icons/demo-uav.png`）、雷达=**回落圆点**（配置里故意指向不存在的 URL，日志给出可读原因与失败计数）、电子/通信=**直接画点**；三条轨迹线宽 3 / 6 / 1 px，最后一条虚线 |
| 清除样式配置 | 调用 `MapDraw.setStyle(null)` → 全部回到"圆点 + 2px 虚线轨迹"，即**未接入本能力时的画法**；日志里位图计数归 0 |

> 纪律口径：这两个按钮验证的是"**新增能力可选**"——不点它们时，无人机与轨迹的画面与接入前逐项一致。

## 四、自动化自检（可选）

`examples/acceptance-smoke.mjs` 用无头 Chrome 自动跑一遍上面这组按钮并打印结果，用于回归：

```bat
:: 1) 先起浏览器调试实例（独立临时 profile，不碰你的浏览器）
set TMPPROF=%TEMP%\map2d-smoke
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --remote-debugging-port=9222 --user-data-dir=%TMPPROF% about:blank

:: 2) 跑自检（需要先 npm run dev:host）
node examples\acceptance-smoke.mjs
```

输出形如：

```
① 面板与清单: {"面板在":true,"汇总行":"93 条需求：已完成 58 · 待完成 35", ...}
② ✓ 开启全部控件  →  ...
③ 指标面板: {"指标行":"帧率 144 fps ｜ 瓦片缓存 109 ｜ 提交 0.3 ms ｜ 堆 43 MB", ...}
```

> 跑完请关掉那个无头实例并删掉 `%TMPPROF%`——**不要让它长期挂着**（会与正常浏览器争用进程状态）。

### 位图图标/线宽的真机自证（本批新增，退出码 0/1）

`_acceptance/marker-style-acceptance.mjs` 用无头 Chrome 断言三件事：
**① 不给新字段 → 行为与今天一致**、**② 图标 URL 无效 → 回落为点且有可读原因**、**③ 有效位图 → 真的画出位图**。

```bat
:: 1) 先起独立宿主（另开一个终端常驻）
cd /d <你的路径>\mapApp\map-2d
npm run dev

:: 2) 再跑自证（脚本自己拉起/关闭无头 Chrome，并现场生成测试用 PNG）
node _acceptance\marker-style-acceptance.mjs
```

输出形如（最后一行是结论，退出码 0 = 全过）：

```
  ✓ 未配置样式时 getStyle() 为 null
  ✓ 无人机圆点半径 = 5（改造前取值） —— radius=5
  ✓ 轨迹线宽 = 2（改造前取值） —— width=2
  ✓ 坏图标：回落为点（未标 hasIcon） —— hasIcon=false
  ✓ 坏图标：失败原因可读（含 HTTP 状态或错误文本） —— reason="The source image could not be decoded."
  ✓ 好图标：要素升级为位图（hasIcon=true） —— iconSize=1.166…
  ✓ 通过 38 / 失败 0
[marker-style] PASS：位图图标可用；不给新字段时行为不变；URL 无效时回落为点且有可读原因
```

> 脚本会把测试图标写到 `public/icons/acceptance-uav.png`，跑完自动删除（该目录已在 `.gitignore` 里）；
> 加 `--keep` 可以保留临时 profile 与图标，便于人工排查。

**纯函数自检**（不需要浏览器、不需要起服务）：

```bat
node scripts\unit-test.mjs
```
