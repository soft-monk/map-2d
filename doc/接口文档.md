## 1. 快速开始

```ts
// 1) 安装依赖（源码模块：把 map-2d/ 目录放进项目，或指向本地路径）
//    仅需 maplibre-gl / react / zustand

// 2) 在入口注册样式
import 'maplibre-gl/dist/maplibre-gl.css'

// 3) 挂地图
import { MapView, MapToolbar, Compass, MapDraw } from '@map2d'

export const Situation: React.FC = () => (
  <div style={{ position: 'absolute', inset: 0 }}>
    <MapView data={mapData}>{/* children 作为地图内浮层 */}
      <MapToolbar />
      <Compass />
    </MapView>
  </div>
)

// 4) 画图（不碰 MapLibre）
MapDraw.set('target', [{ id: 'T-1', lng: 116.45, lat: 39.88, threat: 'high' }])
```

`mapData` 的形状见 §3.1；最小可用对象只要求 `config` 与各数组字段。

## 3. 数据契约

### 3.1 `MapData`（地图容器的唯一入参）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `config` | `MapConfigData \| null` | 是（可为 null） | 视角与底图配置；为 null 时用模块内置默认视角 |
| `scenarioKey` | `string` | 是 | 场景标识（影响分区与阶段图层） |
| `phase` | `'T0'…'T7'` | 是 | 当前阶段（影响哪些图层可见） |
| `targets` | `Target[]` | 是 | 目标台账 |
| `selectedTargetId` | `string \| null` | 否 | 当前选中目标（触发锁定框） |
| `groups` | `Group[]` | 是 | 集群编组 |
| `uavs` | `UavPosEvent[]` | 是 | 无人机实时位置 |
| `edges` | `LinkEdge[]` | 是 | 链路边 |
| `topology` | `LinkTopology \| null` | 是 | 链路拓扑（提供节点坐标） |
| `track` | `TargetTrackPoint[]` | 是 | 目标轨迹点 |

> 字段缺失时按"空数组/默认值"处理，不抛错（便于宿主逐步接入）。

### 3.2 `MapConfigData`

| 字段 | 类型 | 说明 |
|---|---|---|
| `center` | `[lng, lat]` | 初始中心 |
| `zoom` | `number` | 初始层级 |
| `minZoom` / `maxZoom` | `number` | 缩放范围 |
| `basemap.tileUrlTemplate` | `string` | 本地瓦片模板，如 `/tiles/raster/{z}/{x}/{y}.jpg` |
| `basemap.styleUrl` | `string?` | 在线样式 URL；**优先级高于瓦片模板** |
| `basemap.attribution` | `string` | 版权署名文本（是否显示由 `MAP_OPTIONS.showAttribution` 决定） |
| `basemap.fallback` | `string?` | 契约兼容字段（当前前端不据此改色） |
| `video` | `{name,url}[]?` | 与地图无关的透传字段，便于宿主复用同一配置对象 |

### 3.3 图元类型（`MapDraw` 的入参形状）

| 类型 | 关键字段 | 必填 |
|---|---|---|
| `AreaItem`（区域） | `id`、`polygon: [lng,lat][]`、`color?`、`label?`、`dashed?`、`opacity?` | id、polygon |
| `DroneItem`（无人机） | `id`、`lng`、`lat`、`type?`(optical/radar/electronic/comm)、`color?`、`label?` | id、lng、lat |
| `TargetItem`（目标） | `id`、`lng`、`lat`、`threat?`(high/mid/low)、`status?`(red/yellow/gray)、`color?`、`label?`、`selected?` | id、lng、lat |
| `LinkItem`（链路） | `id`、`from: [lng,lat]`、`to: [lng,lat]`、`state?`(green/yellow/red)、`color?`、`label?` | id、from、to |
| `TrackItem`（轨迹） | `id`、`points: [lng,lat][]`、`color?`、`dashed?` | id、points |
| `ScanItem`（扫描覆盖） | `id`、`lng`、`lat`、`radiusKm`、`color?`、`label?` | id、lng、lat、radiusKm |
| `PulseItem`（脉冲） | `id`、`lng`、`lat`、`color?`、`radiusKm?` | id、lng、lat |
| `ClusterItem`（集群） | `id`、`lng`、`lat`、`name?`、`color?` | id、lng、lat |
| `LabelItem`（标注） | `id`、`lng`、`lat`、`text`、`color?`、`size?`、`radius?` | id、lng、lat、text |

**默认配色**（未给 `color` 时）：

| 场景 | 取值 |
|---|---|
| 威胁 | high `#ef4444` ｜ mid `#f59e0b` ｜ low `#22d3ee` |
| 目标状态 | red `#ef4444` ｜ yellow `#f59e0b` ｜ gray `#8b93a7` |
| 无人机类型 | optical `#22d3ee` ｜ radar `#f59e0b` ｜ electronic `#a855f7` ｜ comm `#22c55e` |
| 链路状态 | green `#22c55e` ｜ yellow `#f59e0b` ｜ red `#ef4444` |
| 其它 | 区域 `#22d3ee` ｜ 轨迹 `#ef4444` ｜ 扫描 `#38bdf8` ｜ 脉冲 `#22d3ee` ｜ 集群 `#8b5cf6` ｜ 标注 `#cfe3f5` |

## 4. 组件接口

### 4.1 `<MapView data={MapData}>`

| prop | 类型 | 必填 | 说明 |
|---|---|---|---|
| `data` | `MapData` | 是 | 见 §3.1。**配置只在挂载时读取一次**；运行中改视角请用 `mapCommands` 或改 `config` 对象（会触发平滑移动） |
| `children` | `ReactNode` | 否 | 渲染在地图之上的浮层（工具条、图层面板、指北针等） |

行为约定：

- 拖拽平移、滚轮/双击缩放、二维锁定（禁旋转与俯仰）、比例尺与缩放按钮（当前默认显示，后续改为按需，见需求 M2-CTRL-01）；
- 换 `config.center/zoom` → 平滑移动（600 ms）；换 `basemap` → 重建样式并**自动重放已绘图元**；
- 瓦片失败只累计告警，不隐藏图层；
- 卸载时销毁地图实例。

### 4.2 `<MapToolbar />`

无 props。提供：选择 / 图层（展开图层面板）/ 清屏 / 全屏。测距、区域、新建、标绘为占位（禁用状态）。

### 4.3 `<LayerPanel />`

无 props。10 个图层分组的开关面板，开关状态跨底图切换保留。也可由工具条的「图层」按钮控制显隐。

### 4.4 `<Compass />`

无 props。右下区域常显指北针，随 bearing 旋转，点击复位正北（当前恒指正北，因地图锁定二维）。

### 4.5 `<MapModeBadge mode={string} />`

| prop | 类型 | 说明 |
|---|---|---|
| `mode` | `string` | 显示模式名称；通常用 `displayModeOf(scenarioKey, phase)` 取 |

## 5. 绘制接口 `MapDraw`

所有方法同步返回；数据在模块内部按类型集合管理，变更即触发对应图层增量刷新。

| 方法 | 签名 | 说明 |
|---|---|---|
| `set` | `set<K>(kind: K, items: DrawSnapshot[K])` | **整组替换**该类型全部图元 |
| `add` | `add<K>(kind: K, item: DrawSnapshot[K][number])` | 新增或更新单个图元（按 `id` 覆盖） |
| `remove` | `remove(kind, id: string)` | 删除单个图元 |
| `clear` | `clear(kind?)` | 不传清空全部图元；传则清空该类 |
| `list` | `list<K>(kind: K): DrawSnapshot[K]` | 读取该类图元副本 |
| `export` | `export(): DrawSnapshot` | 导出全部图元（可 JSON 序列化） |
| `load` | `load(snapshot: Partial<DrawSnapshot>)` | 导入快照（整体覆盖） |
| `render` | `render()` | 手动重绘（换底图后由模块自动调用；宿主一般不需要） |

`kind` 取值（`PrimitiveKind`）：`'area' | 'drone' | 'target' | 'link' | 'track' | 'scan' | 'pulse' | 'cluster' | 'label'`

```ts
// 示例：区域 + 目标 + 扫描覆盖
MapDraw.set('area', [{ id: 'A-1', polygon: [[116.30,39.94],[116.42,39.95],[116.44,39.88]], color: '#3b82f6', label: 'A 区' }])
MapDraw.add('target', { id: 'T-1', lng: 116.452, lat: 39.878, threat: 'high', status: 'red', selected: true })
MapDraw.add('scan', { id: 'S-1', lng: 116.365, lat: 39.912, radiusKm: 6, label: '光电侦察覆盖' })

// 存档 → 恢复
const snap = MapDraw.export()
MapDraw.clear()
MapDraw.load(snap)
```

**注意事项**

- `radiusKm` 按当前缩放换算成像素；缩放变化时模块会自动重算（模块内部监听 `zoomend`）；
- 扫描/脉冲的半径是**地理尺寸**，不会因缩放而改变实际覆盖范围；
- 同一 `id` 重复 `add` 视为更新；`remove` 时若 `id` 不存在则无副作用。

## 6. 视角命令 `mapCommands`

| 方法 | 签名 | 说明 |
|---|---|---|
| `setView` | `setView(lng, lat, zoom?, durationMs = 0)` | 设置视角；`durationMs > 0` 时平滑过渡，否则瞬间定位（`zoom` 省略保持当前） |
| `flyTo` | `flyTo(lng, lat, zoom?, durationMs = 900)` | 飞行（带抛物线过渡） |
| `focus` | `focus(lng, lat, zoom = 13)` | 聚焦某点，默认街道级 |
| `resetView` | `resetView(config?: MapConfigData \| null)` | 复位到配置的初始视角（无配置时回北京 z11） |
| `zoomBy` | `zoomBy(delta)` | 相对缩放（正数放大） |
| `getViewport` | `getViewport(): MapViewport` | 读取当前视口 `{lng, lat, zoom, bearing}`；未就绪返回全 0 |
| `isReady` | `isReady(): boolean` | 地图是否已创建，可用于轮询等待 |

```ts
if (mapCommands.isReady()) mapCommands.focus(116.452, 39.878, 14)
mapCommands.flyTo(116.4, 39.9, 12)
const vp = mapCommands.getViewport()
```

## 7. 图层管理 `LayerManager`（高级用法）

一般不需要直接调用（`MapDraw` 已覆盖绘制需求）；以下两类场景会用到：**批量灌业务数据**、**直接写 GeoJSON**。

**分组显隐**

| 方法 | 说明 |
|---|---|
| `setGroupVisible(group: LayerGroup, visible: boolean)` | 开关某分组（10 组：area/pulse/scan/link/group/track/trail/target/uav/mark） |
| `isGroupVisible(group)` / `hiddenGroups()` | 查询 |
| `applyVisibility()` | 把当前显隐状态重新应用（幂等） |

**业务数据入口（给数组即出图）**

| 方法 | 说明 |
|---|---|
| `setTargets(targets, selectedId?)` | 目标（含选中态） |
| `setGroups(groups)` | 集群编组 |
| `setUavs(list)` | 无人机位置 |
| `setLinks(edges, nodes)` | 链路（节点坐标来自 `nodes`） |
| `setTrack(points)` | 目标轨迹 |
| `setScenario(key)` / `setPhase(phase)` | 场景与阶段（影响分区与图层可见性） |

**坐标/GeoJSON 显式入口**

`setAreaFeatures(fc)`、`setScanFeatures(fc)`、`setLinkFeatures(fc)`、`setGroupFeatures(fc)`、`setTargetFeatures(fc)`、`setUavFeatures(fc)`、`setTrackFeatures(fc)`、`setMarkers(fc)`、`setPulseItems(seeds)`、`setPulseSeedsPublic(seeds)`、`clearAll()`

> `clearAll()` 只清动态图层，不影响底图。

## 8. 模块 UI 状态 `useMapUiStore`

const clearMode = useMapUiStore((s) => s.clearMode)

### 10.1 控件按需显示（M2-API-05）— ✅ 已实现

```ts
import { mapCommands, MAP_OPTIONS } from '@map2d'

mapCommands.showControls(['compass', 'scale'])          // 只显示这两个
mapCommands.showControls(['coords'], false)             // 关闭某一类
mapCommands.toggleControl('zoom')                        // 单个切换
mapCommands.getControls()                                // → ['compass', 'scale']
mapCommands.getControlState()                            // → { compass:true, coords:false, zoom:false, scale:false }

// 或改默认值（模块初始化时读一次；适合"某类控件永远显示"的项目）
MAP_OPTIONS.controls = { compass: true, coords: true, zoom: false, scale: false }
```

**自绘控件的渲染位置**：`<Compass />` 与 `<CoordReadout />` 读同一份状态，宿主把它们放进 `<MapView>` 即可；
不想用模块状态时，给 `<Compass force />` 可强制显示（由宿主自己决定何时渲染）。

| 控件 key | 说明 | 默认 |
|---|---|---|
| `compass` | 指北针（随方向旋转、点击复位正北） | 不显示 |
| `coords` | 鼠标位置经纬度（跟随光标刷新） | 不显示 |
| `zoom` | 缩放按钮 `+ / −` | 不显示 |
| `scale` | 比例尺（公制） | 不显示 |

**约定**：不调用 `showControls` 时，地图上只有底图与绘制物——对应 M2-CTRL-01 的验收（"未调用接口时地图上只有底图与绘制物"）。

### 10.2 图元显隐与批量提交（M2-DRAW-03 / M2-API-07）— ✅ 已实现

```ts
// 单个图元显隐：数据保留，只是不画
MapDraw.hide('target', 'T-1')
MapDraw.show('target', 'T-1')
MapDraw.setVisible('target', 'T-1', false)
MapDraw.hideAll('drone')       // 整类
MapDraw.showAll()              // 全部恢复

// 批量提交：中间不渲染，退出时按受影响类型各提交一次（单帧渲染）
MapDraw.batch(() => {
  for (let i = 0; i < 2000; i++) MapDraw.add('drone', { id: 'D' + i, lng: 116 + i * 1e-4, lat: 39.9 })
})
// 返回受影响类型清单，例如 { kinds: ['drone'], rendered: 1 }
```

**约定**：`hide` 不影响 `list()` / `export()` 的结果（数据仍在）；`batch` 内可以做任意次增删改，只渲染一次。

### 10.3 底图管理（M2-API-10 ~ 13）— ✅ 已实现

```ts
import { basemaps } from '@map2d'

// 声明清单（初始化时或运行中）
basemaps.register({ id: 'satellite', name: '卫星影像', type: 'raster',
                    tiles: '/tiles/raster/{z}/{x}/{y}.jpg', minZoom: 3, maxZoom: 14,
                    attribution: 'Esri, Maxar' })
basemaps.register({ id: 'road', name: '路网', type: 'raster', tiles: '/tiles/road/{z}/{x}/{y}.png' })
basemaps.register({ id: 'dark', name: '在线深色', type: 'style',
                    styleUrl: 'https://.../style.json' })
basemaps.setList(defs)            // 也可以用一份清单整体设置（清单可从后端接口拉）

// 查询与切换
basemaps.list()                   // → [{ id, name, type, minZoom, maxZoom, metersPerPixel, isCurrent }]
basemaps.current()                // → 当前底图 def
const r = await basemaps.switch('road')
// 成功 → { ok: true, current: {...} }；失败 → { ok: false, reason: 'not-found' | 'already-current' | ... }

// 切换通知
const off = basemaps.onChange((def) => console.log('底图已切到', def.name))
off()                             // 取消订阅

// 运行中增删
basemaps.unregister('road')       // 若移除的是当前底图 → 回落到清单第一套并广播一次变更
```

**约定**（对应 M2-BASE-10 ~ 13 的验收）：

| 项 | 行为 |
|---|---|
| 切换粒度 | **整幅替换**：同一时刻只有一套底图生效，不做叠加与混合 |
| 切换后 | 视角不变、已绘图元不丢、图层分组开关与控件开关保留 |
| 无效 id | 返回 `{ ok: false, reason }`，**不抛异常**、不改动当前底图 |
| 在线底图 | `type: 'style'` 由 `styleUrl` 提供；在线卡顿属在线源自身问题，模块不做特殊处理 |

### 10.4 瓦片精度上限（M2-API-06）— ✅ 已实现

```ts
import { mapCommands } from '@map2d'

// 三种等价写法（按地面分辨率 = 米/像素；也可直接给层级）
mapCommands.setTilePrecisionLimit({ maxMetersPerPixel: 10 })   // 约等于 z14
mapCommands.setTilePrecisionLimit({ maxZoom: 12 })
mapCommands.setTilePrecisionLimit(null)                        // 取消限制（默认）

mapCommands.getTilePrecisionLimit()   // → { maxMetersPerPixel: 10, maxZoom: 14 } | null
```

| 项 | 说明 |
|---|---|
| 默认 | **不限制**：视口在哪一级就用哪一级瓦片 |
| 超限行为 | 硬边界：超过上限的层级**不再请求瓦片**，改用已加载的较粗瓦片放大显示（画面连续但不更清晰） |
| 作用范围 | **仅本地栅格底图**；`type: 'style'` 的在线底图不受约束 |
| 换算关系 | `米/像素(z, lat) ≈ 156543.03392 × cos(lat) / 2^z`；接口以赤道值换算，偏保守 |

### 10.7 手绘与编辑（M2-DRAW-08 / 12 / 14）— ✅ 已实现

**组件**：`<DrawLayer />` 放进 `<MapView>` 即可（模块自带的演示宿主已经放了）。量算浮层与"已落 N 点"提示由它自己渲染。

**进入/退出绘制**

```ts
mapCommands.setDrawMode('point')          // 落点（单击即完成）
mapCommands.setDrawMode('line')           // 折线 → 默认写入 route（航线）
mapCommands.setDrawMode('area')           // 面   → 默认写入 area（区域）
mapCommands.setDrawMode('measure-line')   // 测距（不落图元）
mapCommands.setDrawMode('measure-area')   // 测面（不落图元）
mapCommands.setDrawMode('none')           // 退出
mapCommands.getDrawMode()                 // → 当前模式
mapCommands.setDrawKind('track')          // 改绘制结果写入哪一类（默认：点→label、线→route、面→area）
```

**绘制时的键鼠约定**

| 操作 | 效果 |
|---|---|
| 单击 | 落一个顶点 |
| 双击 / `Enter` | 完成绘制（面少于 3 点、线少于 2 点会提示并保持绘制态） |
| `Backspace` / `Delete` | 退回上一个顶点 |
| `Esc` | 取消本次绘制（已落顶点丢弃，**未完成的内容不会进图元集合**） |

> 重要语义：绘制过程中的"预览线/预览面/顶点手柄"用独立临时源渲染，**不进 `list()` / `export()`**。
> 只有完成（双击/Enter/落点）后才通过 `MapDraw.add()` 落库，因此导出、显隐、事件命中等能力对绘制结果同样成立。

**图元编辑**

```ts

mapCommands.getEditTarget()                // → { kind, id, dragging }
mapCommands.insertVertexAt(0)              // 在第 0 段后插入顶点（取段中点）
mapCommands.removeVertexAt(0)              // 删顶点；区域最少 3 个、折线最少 2 个
mapCommands.finishEdit()                   // 退出编辑态
```

编辑态下顶点会显示为可拖拽手柄（`data` 层），拖动即调用 `MapDraw.add(kind, { ...item, 新顶点 })` 回写——
所以 `list()` 立即可读到最新坐标。

预览顶点会被替换为已有点坐标。候选点来自所有已有图元的顶点。

### 10.9 视图状态序列化（M2-API-08）— ✅ 已实现（另含图片导出 M2-API-09）

**视图状态序列化（M2-API-08）**

```ts
// 导出：视角 + 显示模式 + 图层开关 + 分组透明度 + 控件开关 + 当前底图 + 精度上限 +（默认）图元
const state = await mapCommands.exportViewState()
// → { version:1, at, view:{lng,lat,zoom,bearing}, displayMode, activeTool,
//     layers:{...}, layerOpacity:{...}, controls:{...}, basemap, tileMaxMetersPerPixel, primitives }

// 只要"视图"不要图元（例如只想记住用户看到哪儿了）
const viewOnly = await mapCommands.exportViewState({ withPrimitives: false })

// 恢复：传整个快照或其子集
await mapCommands.restoreViewState(state, { duration: 600 })
// → { ok:true, applied:['basemap=road','tileMax=null','layers','layerOpacity','controls=compass,legend','view','primitives'] }
```

**恢复顺序是有讲究的**（模块内部固定）：底图 → 精度上限 → 图层开关/透明度 → 控件 → 视角 → 图元。
原因是底图切换会**重建整个样式**，反过来做的话前面设好的图层状态与视角会被冲掉。

`applied` 数组说明每一项是否真的落地了；底图不存在时不会中断，而是记为 `basemap 跳过（原因）` 继续恢复其余部分。

**图片导出（M2-API-09）**

```ts
const dataUrl = await mapCommands.exportImage({
  type: 'image/png',      // 或 'image/jpeg'
  quality: 0.92,          // JPEG 质量
  withControls: true,     // 是否把已开启的控件（指北针/经纬度/图例/比例尺）合成进去
  background: '#0a1420',  // 底图未加载区域的底色
})

await mapCommands.downloadImage('态势图.png')   // 直接触发下载，返回 dataURL
```

> 导出依赖 WebGL 保留缓冲区：模块默认已开 `preserveDrawingBuffer: true`；
> 若宿主自建 Map 实例，需要自己开，否则可能取到全黑图。
> 控件合成是"底色 + 位置"的简化合成（不引 html2canvas），画布内容为像素级原样。

**渲染时机计数（M2-NFR-14）**

```ts
mapCommands.getRenderTiming()
// → { writes, renders, coalesced, writesPerSec, rendersPerSec }
mapCommands.getStats().render   // 同一份数据（在运行指标里）
```

口径：`writes` 是绘制 API 的写入调用次数（含 `batch` 内部的每次调用），
`renders` 是真正落到地图数据源的次数（`setData`）。
`batch()` 内 50 次写入实测为 **1 次渲染**；非批量写入是 1:1（语义明确，不做隐式合并）。

## 12. 错误与降级约定

| 场景 | 模块行为 | 宿主应对 |
|---|---|---|
| 地图未就绪就调命令 | `mapCommands` 静默返回；`isReady()` 为 false | 轮询 `isReady()` 或等 `data.config` 到位 |
| 瓦片目录缺失 / 服务未起 | 回落纯色底，页面与交互正常；控制台按累计次数告警 | 无需特殊处理；如需提示可自行监听控制台 |
| 单张瓦片 404 | 该处显示缺口底色，不隐藏整层 | 无 |
| 图元数据非法（缺 id/坐标） | 当前实现可能整类渲染异常；**错误边界已设计待实现**（§10.8） | 传入前做最小校验 |
| 未配置 `config` | 使用内置默认视角（北京 z11），不报错 | 无 |
