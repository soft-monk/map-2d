# map-2d · 第三方接入指南

- 版本：v1.0
- 日期：2026-09-12
- 对应需求：**M2-API-17**（第三方接入指南）
- 适用对象：**不在本项目里**、想把地图能力"拷过去用"的团队
- 阅读顺序：本文 → [接口文档.md](./接口文档.md)（查签名）→ [接口稳定性约定.md](./接口稳定性约定.md)（看兼容承诺）

---

## 1. 三条接入路线，先选一条

| 路线 | 适合 | 代价 | 怎么做 |
|---|---|---|---|
| **A. 源码目录拷贝** | 自己的项目、想改内部实现 | 升级要手动合并 | 拷 `map-2d/src` 到自己项目，配好路径别名 |
| **B. git subtree / submodule** | 想跟上游更新 | 需要 git 基础 | 见 §3 |
| **C. 打包成内部 npm 包** | 多个项目共用 | 需要内网 registry | `npm run build` 后按内部规范发布（模块默认 `private: true`） |

> **本项目不发布公共 npm 包**（决策记录 D9）。以下以 **A / B** 为主线。

---

## 2. 必须拷贝什么

```
map-2d/
├─ src/                     ← 必需（模块全部源码）
├─ doc/                     ← 建议带上（接口文档是接入依据）
├─ examples/minimal.tsx     ← 建议带上（最小可运行示例）
├─ package.json             ← 参考依赖版本，不必原样拷
├─ tsconfig.json            ← 参考编译选项
└─ tiles/                   ← ❌ 不要拷进代码仓库（见 §5）
```

**可以不拷**：`src/standalone/`（模块自带的演示宿主）、`examples/benchmark.ts`、`dist/`、`node_modules/`。

---

## 3. 方式 B：git subtree 接入（推荐）

模块在主仓里是 `map-2d/` 子目录，同时可独立成仓。你只需拉那个仓：

```bash
# 首次：作为子仓加进来（放在你项目的 vendor/map-2d）
git subtree add --prefix=vendor/map-2d https://github.com/soft-monk/map-2d.git main --squash

# 之后更新
git subtree pull --prefix=vendor/map-2d https://github.com/soft-monk/map-2d.git main --squash
```

> 主仓侧对应的发布命令是 `scripts/publish-map2d.bat`（`git subtree split --prefix=map-2d`）。

## 4. 依赖与配置清单

### 4.1 运行时依赖（版本必须兼容）

| 依赖 | 版本 | 说明 |
|---|---|---|
| `react` / `react-dom` | ^18 | 组件层 |
| `maplibre-gl` | ^4.7 | 渲染内核（**宿主不应直接调用它**，见 §6） |
| `zustand` | ^4 | 模块内部状态 |

### 4.2 路径别名

模块内部**没有用**路径别名，全部是相对导入——所以只要你把 `src` 放进去就能编译。若你想用 `@map2d` 指向入口：

```jsonc
// tsconfig.json
{ "compilerOptions": { "paths": { "@map2d": ["./vendor/map-2d/src/index.ts"] } } }

// vite.config.ts
resolve: { alias: { '@map2d': path.resolve(__dirname, 'vendor/map-2d/src/index.ts') } }
```

### 4.3 必需：底图瓦片放哪

模块**不内置瓦片**。两种来源选一种：

```ts
// ① 本地瓦片（推荐；解压后目录形如 tiles/raster/{z}/{x}/{y}.jpg）
config: { tileUrlTemplate: '/tiles/raster/{z}/{x}/{y}.jpg' }

// ② 在线样式（矢量/栅格皆可；需外网）
config: { styleUrl: 'https://example.com/style.json' }
```

本地瓦片要能被浏览器直接取到，三种常见做法：

| 做法 | 配置 |
|---|---|
| 放在前端 `public/tiles/`（Vite/Next 静态目录） | 模板 `/tiles/raster/{z}/{x}/{y}.jpg` |
| 由自己的服务端托管（如静态文件中间件） | 模板 `http://<host>:<port>/tiles/raster/{z}/{x}/{y}.jpg` |
| 开发期用 Vite 中间件（模块自带演示宿主就是这么做的） | 见 `vite.config.ts` 的 `localTiles()` |

### 4.4 可选：环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `MAP2D_TILES_DIR` | 演示宿主启动时读取本地瓦片目录 | `./tiles` |

## 5. 数据怎么给（最小可用）

```tsx
import { MapView, MapDraw, mapCommands } from '@map2d'
import type { MapData } from '@map2d'

const data: MapData = {
  config: { center: [116.3974, 39.9093], zoom: 12, tileUrlTemplate: '/tiles/raster/{z}/{x}/{y}.jpg' },
  targets: [{ id: 'T-1', lng: 116.404, lat: 39.915, label: '目标 001', threat: 'high' }],
}

export const App = () => (
  <div style={{ position: 'fixed', inset: 0 }}>
    <MapView data={data} />
  </div>
)
```

**三条约定**（详见接口文档 §3 / §12）：

1. `data` 里**缺字段不报错**，按约定降级（缺 `config` 用内置默认视角，缺数组按空处理）；
2. 图元坐标非法（非数字、缺坐标、多边形顶点不足）**只跳过这一条并上报**，不影响其它图元；
3. 坐标一律 **WGS84 经纬度**，顺序 `[经度, 纬度]`（GeoJSON 惯例）。

### 5.1 除了 props，还能直接用绘制接口

不想走业务数据结构时，用坐标显式接口自己画（11 类图元，见接口文档 §5）：

```ts
MapDraw.set('area', [{ id: 'A-1', polygon: [[116.36, 39.90], [116.42, 39.90], [116.42, 39.94]] }])
MapDraw.add('route', { id: 'R-1', points: [[116.36, 39.95], [116.40, 39.96]], dashed: true })
MapDraw.add('shape', { id: 'C-1', lng: 116.40, lat: 39.91, radiusKm: 3, kind: 'target' })
```

### 5.2 让用户自己画（可选）

把 `<DrawLayer />` 放进 `<MapView>`，然后：

```ts
mapCommands.setDrawMode('area')        // 面绘制；还有 'point' | 'line' | 'measure-line' | 'measure-area'
```

键鼠：单击落点、双击/`Enter` 完成、`Backspace` 退点、`Esc` 取消。绘制中的预览**不进图元集合**。

## 6. 宿主不该做的事（重要）

| ❌ 不要 | ✅ 改为 |
|---|---|
| `import maplibregl from 'maplibre-gl'` 后自己 `new Map()` | 用 `<MapView data={...} />` |
| 访问模块内部路径 `@map2d/src/render/LayerManager` | 用分组级接口：`mapCommands.moveLayerGroup` / `setLayerGroupOpacity` |
| 直接 `map.getLayer('lyr-target')` 改样式 | 用绘制接口的属性覆盖（`color` / `opacity` / `dashed` / `weight`） |
| 监听 `map2d:basemap-change` 内部事件 | 用 `basemaps.onChange(cb)` |
| 自己维护图元数组并与地图同步 | 交给 `MapDraw`，用 `export()` 存档 |

理由：以上内部细节**不在兼容承诺内**（见《接口稳定性约定》§1、§4），升级时可能变。

## 7. 从零跑通（30 分钟路径）

1. **拉代码**：`git subtree add`（§3）或直接拷 `src/`（§2）；
2. **装依赖**：`npm i react react-dom maplibre-gl zustand`；
3. **配别名**：`@map2d` → `vendor/map-2d/src/index.ts`（§4.2）；
4. **放瓦片**：解压瓦片包到静态目录，确认浏览器能直接打开一张，如
   `/tiles/raster/12/3423/1665.jpg`（§4.3）——**打不开就先去解决这个**，别急着调代码；
5. **贴最小示例**：把 `examples/minimal.tsx` 的 `MinimalExample` 挂到你的 App 上；
6. **验证四件事**：能出图 → 能拖拽缩放 → 数据里的目标点出现 → 点目标能拿到回调；
7. **按需开启能力**：控件（`showControls`）、绘制（`setDrawMode`）、底图切换（`basemaps`）、
   状态存档（`exportViewState` / `restoreViewState`）。

### 排障顺序（按命中率）

| 现象 | 先查 |
|---|---|
| 页面全黑但能拖拽 | 瓦片路径/服务不可达；看控制台是否有 404（模块对缺失瓦片只汇总告警，不刷屏） |
| 图元不显示 | 是否在地图 `isReady()` 之后才灌数据（它的语义是"图层已建立"，不是"实例已创建"） |
| 图元不显示且当前阶段是 T0–T2 | 阶段规则本就不显示目标/无人机/集群；`setPhase('T3')` 或改用 T3 之后 |
| 点图元没回调 | 图层被阶段规则或分组开关隐藏了；`getStats().primitives` 能看到数据但看不见图 |
| 控件不显示 | 控件**默认全部不显示**，要 `showControls([...])` |
| 导出图片是全黑 | 需要 WebGL 保留缓冲区——模块已默认开启 `preserveDrawingBuffer`，若你自建了 Map 实例需自己开 |

## 8. 升级与兼容

- 升级前看《接口稳定性约定》§5 变更记录；
- 破坏性变更**必须经过废弃过渡期**（至少一个次版本），期间旧接口仍可用并打印一次提示；
- 宿主自查清单见该文档 §6。

---

## 9. 遇到问题怎么反馈

带上这四项，定位会快很多：

1. 模块版本（主仓 commit 号或子仓 tag）；
2. 浏览器与版本；
3. `mapCommands.getStats()` 的输出（帧率/图元数/瓦片缓存/渲染时机计数）；
4. 控制台里 `[map-2d]` 开头的告警（模块的告警都带该前缀）。
