## 1. 一句话说明

`map-2d` 是一个**运行在浏览器里的二维地图渲染与图元绘制模块**：宿主把数据交给它、调用它的接口，它把地图与图元画在 WebGL 画布上。
它是**纯前端交付物**（源码模块），**没有自己的服务端**；它唯一需要的外部资源是"瓦片图片放在哪里"，而这个地址由接入方配置。

## 3. "前后端"关系说明（重要）

本模块的交付形态决定了它的"前后端"与传统 Web 应用不同：

| 角色 | 是否存在 | 说明 |
|---|---|---|
| 模块自身的前端 | ✅ 存在 | 组件 + 命令接口 + 渲染内核，全部在浏览器内运行 |
| 模块自身的后端 | ❌ **不存在** | 无服务端进程、无数据库、无业务 API；模块不发任何业务请求 |
| 静态文件服务（可选） | ⚠️ 由接入方提供 | 瓦片图片需要一个能被浏览器取到的地址：可以是前端静态目录、任意静态文件服务、对象存储或 CDN |
| 宿主后端（可选） | ⚠️ 由宿主决定 | 若宿主希望由自己的服务下发地图配置或瓦片清单，那是**宿主的接口**；模块只消费传入的配置对象，不定义、不调用任何具体接口 |
| 开发服务器 | ⚠️ 开发期存在 | Vite 开发服务器（用于演示与联调），**不参与生产运行** |

**结论**：模块是"零后端依赖"的前端模块——**没有瓦片服务它也能打开**（回落纯色底），只是底图为空。

## 5. 模块的输入与输出（对外接口速览）

### 5.1 输入：宿主交给模块的东西

| 输入 | 形式 | 内容 |
|---|---|---|
| 地图配置 | 一个配置对象 | 中心点、初始层级、缩放范围、底图（瓦片模板 / 样式 URL / 署名） |
| 业务数据 | 同一对象的数组字段 | 目标、编组、无人机位姿、链路、轨迹（全部**可选**，缺省按空处理） |
| 绘制数据 | 绘制 API 调用参数 | 13 类图元的属性对象（坐标、样式、标签、显隐等） |
| 底图清单 | 底图描述数组 | 标识、名称、类型、模板或样式、层级范围、分辨率、署名 |
| 回放数据 | 轨迹点集 | 每条轨迹：`id` + 带时间戳的点序列 |
| 上下文（可选） | 字符串/枚举 | 场景或流程标识、阶段值；仅用于查宿主注入的映射表与显示模式标签 |
| 配置与开关 | 环境变量 / 开关对象 | 瓦片目录、精度上限、控件开关、主题、样式模板 |

### 5.2 输出：模块交回宿主的东西

| 输出 | 形式 | 内容 |
|---|---|---|
| 地图画面 | WebGL 画布 | 底图 + 图元 + 已开启控件 |
| 图像导出 | dataURL / 下载 | PNG / JPEG（可选是否合成控件） |
| 状态查询 | 同步返回值 | 当前视口、图层开关、控件开关、底图、精度上限、运行指标、降级状态 |
| 状态序列化 | JSON 对象 | 视角 / 底图 / 精度上限 / 图层开关与透明度 / 控件 / 图元（**不含宿主业务数据**） |
| 图元快照 | JSON 对象 | 全部图元，可存档、可再导入 |
| 事件与回调 | 回调函数 | 图元点击/悬停、底图切换、瓦片降级、错误上报、回放进度变化 |

## 6. 连接关系与数据通道

### 6.1 连接拓扑

```
┌─────────────────────────────────────────────────────────────────────┐
│ 浏览器页面                                                          │
│                                                                     │
│  ┌──────────────┐  ① import + props（对象）+ 命令调用（函数）        │
│  │ 宿主应用      │ ─────────────────────────────────────────────┐    │
│  │（任何项目）   │ ◀─────────────────────────────────────────────┘    │
│  └──────────────┘  ② 回调 / 返回值（对象、数组、状态）               │
│         │                                                           │
│         │ 装配 <MapView data={...}>（同页，同一 JS 运行时）           │
│         ▼                                                           │
│  ┌──────────────────────────────┐  ③ JS API（addSource/addLayer）   │
│  │ map-2d 模块（前端）           │ ────────────────┐                 │
│  │  组件层 / 绘制 API / 图层管理  │                 ▼                 │
│  │  / 状态 / 命令门面            │  ④ WebGL 绘制  ┌───────────────┐  │
│  └──────────────────────────────┘ ──────────────▶ │ 地图渲染内核   │  │
│         │                                         │ (maplibre-gl) │  │
│         │ ⑤ HTTP GET（仅取瓦片与样式）             └───────────────┘  │
└─────────┼───────────────────────────────────────────────────────────┘
          ▼
   瓦片 / 样式资源（提供方：接入方自建静态服务、前端静态目录、对象存储或 CDN）
```

### 6.2 通道清单（谁和谁连、怎么连、传什么）

| # | 通信双方 | 连接方式 | 传输内容 | 协议/格式 | 方向 |
|---|---|---|---|---|---|
| ① | 宿主 → 模块 | 同页 JS 调用与组件属性 | 数据对象（`MapData`）、配置对象、图元数组、命令参数 | TypeScript 对象（内存，无序列化） | 宿主 → 模块 |
| ② | 模块 → 宿主 | 函数返回值 / 注册的回调 | 视口、状态对象、图元快照、事件负载 `{kind, id}`、错误 `{kind, id, reason}` | 内存对象 / JSON 可序列化 | 模块 → 宿主 |
| ③ | 模块 → 渲染内核 | JS API | 样式对象、数据源与图层定义、地理数据、相机与控件指令 | JS 调用 + GeoJSON 结构 | 模块 → 内核 |
| ④ | 渲染内核 → 屏幕 | WebGL | 绘制指令与纹理（瓦片位图） | WebGL / GPU | 内核 → 画布 |
| ⑤ | 模块 → 瓦片/样式资源 | HTTP(S) 请求 | 瓦片图片（`{z}/{x}/{y}`）与样式 JSON | HTTP GET，模板地址由配置注入 | 模块 → 资源服务 |
| ⑥ | 模块 ↔ 模块内部 | 自定义事件 / 单例状态 / 命令 | 精度变更、底图变更、降级通知等内部广播 | 浏览器 `CustomEvent` | 模块内 |
| ⑦ | 宿主 ↔ 宿主后端（若存在） | 宿主的接口 | 配置与清单的来源（可选） | 由宿主定义 | 不在模块范围内 |

### 6.3 需要特别说明的三点

1. **没有 WebSocket、没有长连接、没有轮询**：模块不主动维持任何实时连接。实时性由宿主通过 props 更新或命令调用驱动（宿主自己的实时通道与本模块无关）。
2. **没有业务 API 调用**：模块唯一的网络请求是"取瓦片/样式"这类静态资源请求；接口统计与降级判定也只针对这类请求。
3. **可完全离线**：把瓦片放到本地静态目录后，模块在断网环境可完整运行（在线样式底图除外，那是接入方主动配置的外部源）。

## 7. 运行时数据流（时序速览）

```
宿主启动
  ├─ 组装数据对象（业务数据 → 适配层 → MapData）——适配层在宿主侧
  ├─ 渲染 <MapView data={...}>，children 放工具条/面板/指北针等浮层
  └─ 模块：按配置建样式 → 建实例 → 建数据源与图层 → 就绪
数据更新
  ├─ 宿主更新 props（数组变化）
  └─ 模块：增量写入数据源（不重建图层）→ 内核重绘
绘制
  ├─ 宿主调用绘制 API（增删改查/批量/快照）
  └─ 模块：写入图元集合 → 按类型转换为地理数据 → 提交数据源
选择与联动
  ├─ 用户点击图元
  └─ 模块：命中检测 → 触发回调（只带图元身份）→ 宿主据此更新自己的面板
底图切换 / 样式重建
  ├─ 宿主切换底图或改精度
  └─ 模块：重建样式 → 重建图层 → 恢复图层开关与控件 → 重放全部图元
导出
  ├─ 宿主请求图片或状态
  └─ 模块：合成画布为图片 / 序列化视图状态（不含业务数据）→ 返回宿主
```

## 8. 部署与运行方式

| 形态 | 需要什么 | 不需要什么 |
|---|---|---|
| 嵌入宿主（生产） | 宿主前端工程 + 3 个运行时依赖 + 瓦片地址配置 | 不需要本模块的服务端、不需要数据库、不需要特定后端 |
| 独立运行（演示/验收） | Node 18+、本地瓦片目录（可选）、开发服务器 | 不需要任何后端服务；瓦片缺失也能打开 |
| 静态托管 | 打包产物 + 瓦片静态目录 | 不需要 Node 运行时 |
| 局域网/平板访问 | 开发服务器监听全网卡（可配置） | 不需要外网 |

**生产部署清单（最小）**：① 把模块源码（或打包产物）纳入宿主工程；② 配置底图地址（瓦片模板或样式 URL）；③ 在宿主侧写一个"业务数据 → 模块数据对象"的适配函数。

## 10. 外部依赖登记（提供方 / 形态 / 缺失时行为）

| 外部对象 | 提供方 | 形态 | 缺失时行为 |
|---|---|---|---|

## 11. 技术指标速览（实测口径）

| 指标 | 数值 | 口径 |
|---|---|---|
| 单次批量提交 | 2 万点 ≤ 20 ms；5 千多边形 ≤ 20 ms | JS 侧把数据翻译为地理数据并提交的墙钟耗时 |
| 单点更新 | 约 0.2 ms/次 | 点位移动类更新 |
| 帧率 | 约 140 fps（桌面浏览器） | 页面上报口径，非地图渲染帧率上限 |
| 内存占用 | 数十 MB 量级 | 混合负载后堆占用 |
| 渲染负载 | 空载 → 5 万点，像素回读耗时基本持平 | 说明瓶颈在数据翻译侧而非绘制侧 |

> 以上为参考基线；换机器需重跑基准脚本刷新。指标可按需重新测量，不作为对外承诺值。
