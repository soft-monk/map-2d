## 1. 模块是什么

一个**只做二维地图渲染**、可以单独跑也可以嵌进别人的项目、能整目录拷走的模块。

| 项 | 内容 |
|---|---|
| 交付形态 | 源码模块；可整目录拷贝，也可独立成仓（不发布 npm 包） |
| 运行方式 | ① 独立运行：一条命令打开即出图，不依赖后端 ② 嵌入宿主：数据经 props 注入 |
| 依赖 | 仅 `maplibre-gl` / `react` / `zustand`；不依赖后端、宿主 store、宿主组件库 |
| 渲染维度 | 仅二维（Web Mercator 平面），锁定旋转与俯仰 |

**边界（不做）**：三维能力（地形/建筑/2D-3D 切换）；业务逻辑与数据获取；界面框架（导航/业务面板/状态栏）；瓦片切图与分发；后端接口定义。

## 2. 已有功能

### 2.1 地图漫游与交互

| 功能 | 实现位置 |
|---|---|
| 拖拽平移（左键 / 触屏单指） | `ui/MapView.tsx` |
| 缩放：滚轮以光标为中心、双击、`+/−` 控件、触屏双指 | `ui/MapView.tsx` |
| 二维锁定（禁旋转/俯仰，指北针恒指正北） | `ui/MapView.tsx` |
| 初始视角与缩放范围由宿主配置 | `core/types.ts` `MapConfigData` |
| 比例尺（左下，公制） | `ui/MapView.tsx` |
| 指北针（常显 N，点击复位正北） | `ui/Compass.tsx` |
| 视角命令：setView / flyTo / focus / resetView / zoomBy / getViewport / isReady | `core/commands.ts` |
| 换场景/任务时平滑移动视角 | `ui/MapView.tsx`（`easeTo`） |
| 视口回写（坐标与层级供宿主显示） | `core/store.ts` `viewport` |

### 2.2 底图与显示

| 功能 | 实现位置 |
|---|---|
| 本地栅格瓦片底图（`{z}/{x}/{y}` 模板） | `ui/MapView.tsx` `rasterStyle()` |
| 在线样式底图（矢量/栅格样式 URL） | `ui/MapView.tsx` `buildStyle()` |
| 无瓦片兜底（纯色底也能打开、可交互） | `ui/MapView.tsx` `fallbackStyle()` |
| 缺口用深蓝灰地面色、瓦片不淡入（少出现刺眼黑框） | `ui/MapView.tsx` + `core/options.ts` |
| 低清叠底（同模板 z0–6），拖动时先有低清影像 | `ui/MapView.tsx` |
| 运行中切换底图，已绘制图元不丢（图层重建 + 图元重放） | `ui/MapView.tsx` |
| 版权署名开关（默认隐藏，改一个开关即恢复） | `core/options.ts` `MAP_OPTIONS` |
| 瓦片加载失败只告警、不隐藏图层 | `ui/MapView.tsx` |

### 2.3 图层与图元

| 功能 | 实现位置 |
|---|---|
| 10 个图层分组可独立开关，开关状态跨底图切换保留 | `render/LayerManager.ts` |
| 数据驱动渲染：颜色/标签/选中/状态/威胁级别由图元属性决定 | `render/LayerManager.ts` + `primitives/api.ts` |
| 业务数据入口：目标、编组、无人机、链路、轨迹一次给数组即出图 | `render/LayerManager.ts` `setTargets/setGroups/setUavs/setLinks/setTrack` |
| 坐标显式入口：区域/扫描/脉冲/标注/链路/编组/目标/无人机/轨迹 | `render/LayerManager.ts` `setXxxFeatures / clearAll` |
| 增量更新（`source.setData()`，不重建图层） | `render/LayerManager.ts` |
| 脉冲扩散环动画（内部 rAF） | `render/LayerManager.ts` |

### 2.4 绘制 API（宿主不碰 MapLibre）

| 功能 | 实现位置 |
|---|---|
| 9 类图元：区域 / 无人机 / 目标 / 链路 / 轨迹 / 扫描 / 脉冲 / 集群 / 标注 | `primitives/api.ts` |
| 增删改查：`set / add / remove / clear / list` | `primitives/api.ts` |
| 整组导入导出：`export()` / `load(snapshot)`（可 JSON 存档） | `primitives/api.ts` |
| 扫描半径用公里表达，随缩放自动换算像素 | `primitives/api.ts` `kmToPixels` |
| 底图切换后图元自动重放：`render()` | `primitives/api.ts` |
| 内置调色板（威胁/状态/无人机类型/链路状态…），未给色时自动取 | `primitives/api.ts` |

### 2.5 模块 UI 与状态

| 功能 | 实现位置 |

| 模块内部 UI 状态（清屏/工具/面板/图层开关/视口/显示模式） | `core/store.ts` |
| 模块开关集中管理（署名、淡入） | `core/options.ts` |

### 2.6 独立运行与交付

| 功能 | 实现位置 |
|---|---|
| 独立宿主：`npm run dev` → 打开即出图，自带示例图元 | `src/standalone/` |
| 独立宿主控制条：底图切换 / 载入示例 / 清空 / 图层 / 清屏 / 复位视角 | `src/standalone/main.tsx` |
| 开发代理：本地瓦片借用主系统后端（未启动也不报错） | `vite.config.ts` |
| 类型检查与打包（`npm run typecheck` / `npm run build` → `dist/`） | `package.json` |
| 子仓独立发布（整目录可 clone 使用） | 主仓 `scripts/publish-map2d.bat` |
