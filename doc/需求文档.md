## 1. 模块定位

一句话：**把"二维地图该怎么显示、怎么交互、怎么往上画东西"收敛成一个可独立交付的模块。**

| 项 | 内容 |
|---|---|
| 做什么 | 二维底图渲染与交互、图层与图元管理、绘制 API、地图级 UI 控件（工具条/图层面板/指北针） |
| 不做什么 | 业务逻辑、数据获取、界面框架（导航/面板/状态栏）、三维能力 |
| 交付形态 | 源码模块（`private: true`，不发布 npm 包）；可整目录拷贝，也可通过 `git subtree` 独立成仓 |
| 依赖 | 仅 `maplibre-gl` / `react` / `zustand`；**不依赖**任何后端、宿主 store、宿主组件库 |
| 使用方式 | ① 独立运行（自带示例数据）② 嵌入宿主（数据经 props 注入） |
| 渲染维度 | **仅二维**：Web Mercator 平面，锁定 `dragRotate / maxPitch`，指北针恒指正北 |

### 1.1 范围边界（三条硬规则）

1. **模块不做网络数据获取**：所有业务数据由宿主通过 props 注入（`MapData`），模块只负责画。
   唯一的例外是**底图瓦片**请求——那是渲染的必要条件（见 M2-09/M2-10）。
2. **模块不读宿主状态**：模块内只有自己的 UI 状态 store（清屏/图层开关/工具/视口/显示模式）。
3. **模块不含界面框架**：左侧导航、底部状态栏、业务面板都在宿主；模块只提供地图本身与地图级控件。

## 2. 本次明确不做（防止范围回弹）

| 不做的事 | 原因 / 依据 |
|---|---|
| 🚫 三维能力：2D/3D 切换、地形（terrain/DEM）、三维建筑（fill-extrusion / 3D Tiles）、楼层与室内 | 主系统 v1.2 范围收敛已放弃（TRD D12） |
| 🚫 手绘交互：鼠标画点/线/面（测距、区域绘制、新建、标绘） | 当前版本用绘制 API 驱动；交互式手绘未实现（工具为占位） |
| 🚫 瓦片数据管线：切图、抓取、打包、分发 | 属主系统构建脚本职责（`scripts/fetch_tiles.*`、`install_tiles.bat`） |
| 🚫 业务语义：阶段流程、目标台账、威胁评级、链路状态机 | 属宿主业务；模块只认图元的外观属性（颜色/标签/选中/威胁级别字符串） |
| 🚫 地图之外的 UI：顶栏、右侧面板、语音入口、视频浮层、告警浮层 | 属宿主；模块只提供"清屏"所需的开关量（M2-19） |
| 🚫 后端接口定义 | 模块只消费 `MapConfigData` 形状的配置；接口契约在主仓《开发接口契约规格书》 |

## 3. 模块需求条目

### 3.1 地图漫游与交互（M2-01 ~ M2-08）

| 编号 | 需求 | 现状 | 说明 / 实现位置 |
|---|---|---|---|
| M2-01 | **拖拽平移**：左键拖拽平移地图；触屏单指拖动 | ✅ | MapLibre 原生；`ui/MapView.tsx` 初始化 `dragRotate:false`（只平移不旋转） |
| M2-02 | **缩放**：滚轮以**光标为中心**缩放；双击放大；`+/−` 控件；触屏双指 | ✅ | `NavigationControl(showCompass:false)` + MapLibre 默认交互 |
| M2-03 | **比例尺**：常显于地图左下，公制 | ✅ | `ScaleControl({ maxWidth:120, unit:'metric' })` |
| M2-04 | **指北针**：常显 N 指示；点击复位正北 | ✅ | `ui/Compass.tsx`（自绘 SVG，位置 `top:92 right:12`） |
| M2-05 | **缩放范围**：由宿主配置 `minZoom/maxZoom` 决定，未给则用模块默认（3 / 16） | ✅ | `MapConfigData.minZoom/maxZoom`；后端当前下发 3–15 |
| M2-06 | **初始视角**：由宿主配置 `center/zoom` 决定；未给时用模块内置默认（北京，z11） | ✅ | `DEFAULT_CENTER / DEFAULT_ZOOM` |
| M2-07 | **视角切换**：宿主换场景/任务时，地图平滑移动视角 | ✅ | `MapView` 监听 `config` 变化 → `easeTo({ duration:600 })` |
| M2-08 | **二维锁定**：禁止旋转与俯仰（保证态势图方向恒定） | ✅ | `dragRotate:false`、`pitchWithRotate:false`、`touchPitch:false`、`maxPitch:0` |

### 3.2 底图（M2-09 ~ M2-12）

| 编号 | 需求 | 现状 | 说明 / 实现位置 |
|---|---|---|---|
| M2-09 | **本地栅格瓦片底图**：按 `{z}/{x}/{y}` 模板请求，服务端静态托管 | ✅ | `rasterStyle()`；瓦片路径由宿主配置（当前 `/tiles/raster/{z}/{x}/{y}.jpg`） |
| M2-10 | **在线样式底图**：支持直接给样式 URL（矢量/栅格均可），优先于瓦片模板 | ✅ | `MapConfigData.basemap.styleUrl`；独立宿主用于在线底图（demotiles / OpenFreeMap / CARTO 深色） |
| M2-11 | **运行中切换底图**：不刷新页面即可换底图，且**已绘制的图元不丢** | ✅ | `setStyle` 后重建图层并 `MapDraw.render()` 重放（见《设计文档》§6.3） |

### 3.3 缺口观感与加载表现（M2-13 ~ M2-14）

| 编号 | 需求 | 现状 | 说明 |
|---|---|---|---|
| M2-13 | **缺口不刺眼**：瓦片未到位处露出的是深蓝灰"地面色"，不是纯黑；栅格瓦片不做淡入（到达即显示） | ✅ | 缺口底色 `#16283a`；`raster-fade-duration` 取 `MAP_OPTIONS.rasterFadeDuration`（默认 0）；低清叠底层（同模板、`maxzoom:6`）保证拖拽时先有低清影像 |
| M2-14 | **缩放/拖拽过程中不出现整屏深蓝方块** | ⏸ **暂缓** | 已复现并定位：方块 = 缺口底色本身（实测 `rgb(19,38,57)`、整屏、色彩数 1）；成因① 缩放逐级拉新金字塔层期间无内容；成因② MapLibre 会主动卸载远处瓦片，回头路需重新解码上传。曾试"启动预热低清地板层 + 底图源 overzoom"，指标改善（331ms→0 帧 / 245ms→33ms）但**用户实测体感变卡顿**，已整体回退。完整记录见主仓《地图相关需求专篇》CAND-MAP-14 / §2.3，本轮不做 |

## 6. 暂缓项（本轮不做，记录以免重复踩坑）

**M2-14 底图加载观感优化** —— 现象：缩到最小后拖拽、或缩放过程中出现整屏纯深蓝方块，约 0.3–0.5 s 后出图；"拖到别处再拖回来"也会复现。

已定位（实测，非推测）：

| 项 | 结论 |
|---|---|
| 方块是什么 | **缺口底色本身**：实测 `rgb(19,38,57)`、占屏 100%、色彩数 = 1。不是瓦片缺失，也不是 MapLibre 默认背景 |
| 成因一 | 缩放过程中**经过的中间层级**没有可用瓦片：底图源默认逐级请求新金字塔层，期间整屏无内容 |
| 成因二 | "拖回去"也复现：MapLibre 会**主动卸载远处瓦片**（`maxTileCacheSize`，默认约 100–200 张），回头路要重新解码 + 上传纹理，赶不上那一帧 |
| 与"数据多少"无关 | 瓦片躺在硬盘上 ≠ 已进内存；缓存头只能免掉网络，免不掉解码与上传 |

试过并已回退的两招（数据留档，便于日后重启）：

| 尝试 | 实测效果 | 回退原因 |
|---|---|---|
| 全球低精度地板层**启动预热**（z0–5，1,365 张 / 10.8 MB，启动页进度条联动） | 整屏底色 331 ms → 0 帧 | 体感变卡顿 |
| 底图源 `maxzoom` 压到地板层（**overzoom**：缩放时用低清瓦片放大顶住） | 245 ms → 33 ms | 同上，一并回退 |

**回退基准**：模块内容 = 子仓提交 `ed8bb2a`；历史实现留在主仓提交 `caf4e59`（预热 + 瓦片缓存头）与 `cbec72e`（z5 + overzoom），需要时 `git show` 直接取用。

后续可考虑的方向（本轮不做）：Service Worker 瓦片缓存 / 扩大高清瓦片覆盖 / 调整 `maxTileCacheSize` 与 `raster-fade-duration` / 接受现状（首次浏览有短暂底色，之后正常）。
