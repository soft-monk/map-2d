# map-2d · 接口稳定性约定与变更记录

- 版本：v1.0
- 日期：2026-09-12
- 对应需求：**M2-API-15**（接口稳定性约定）
- 适用范围：模块对外导出的一切内容——`src/index.ts` 导出的组件、函数、对象、类型

---

## 1. 什么算"对外接口"

只有 **`src/index.ts` 导出的东西**算对外接口。其余一律是内部实现：

| 算对外接口（受本约定保护） | 不算（随时可改，不另行通知） |
|---|---|
| `MapView` / `MapToolbar` / `LayerPanel` / `Compass` / `CoordReadout` / `Legend` / `DrawLayer` 组件 | `src/render/*`（渲染层内部） |
| `MapDraw`、`mapCommands`、`LayerManager` 上的公开方法 | `src/core/instance.ts`（地图单例引用，测试与内部用） |
| `useMapUiStore`、`useInteraction` 的状态字段与方法 | 图层 id、数据源 id（`lyr-*` / `src-*`） |
| `primitives/api.ts` 里的图元类型（`AreaItem` 等） | 内部工具函数（未导出的） |
| `MAP_OPTIONS` 配置项、`basemaps` 注册表、几何函数 | DOM 结构与内联样式细节（**`data-map2d-*` 标记除外，见 §4**） |

> 判断方法：`import { ... } from '@map2d'` 能拿到的就是对外接口。

## 2. 变更分级与承诺

| 级别 | 含义 | 处理方式 |
|---|---|---|
| **Patch** | 内部实现调整、性能优化、修 bug | 不改接口；直接发布 |
| **Minor** | **新增**接口/可选参数/图元类型/控件 key | 向后兼容；在 §5 记录；升级无需改宿主代码 |
| **Major** | **破坏性变更**：删除或改名导出、改必填参数、改默认值语义、改返回值结构 | 走 §3 的废弃流程；在本文件顶部标注；提供迁移说明 |

**默认值变更视为破坏性**。例如"控件默认不显示"这条语义如果反转，就是 Major——宿主会突然多出控件，必须走废弃流程。

---

## 3. 废弃（Deprecation）流程

破坏性变更**不允许直接删除**，必须经过至少一个 Minor 版本的过渡期：

1. **标注**：在类型/函数的 JSDoc 里加 `@deprecated 用 xxx 代替，将在 vX.Y 移除`，并在控制台打印一次提示（只在首次调用时打印，避免刷屏）；
2. **共存**：旧接口继续可用且行为不变，至少保留一个 Minor 版本；
3. **记录**：写入本文件 §5 变更记录的"废弃"栏，注明替代方案与计划移除版本；
4. **移除**：仅可在下一个 Major 版本移除，并在 §5 标注"已移除"。

过渡期长度：本项目按"**至少一个 Minor 版本**"执行；若旧接口有安全问题或严重性能问题，可缩短为"当版本内标注 + 下个版本移除"，但必须在 §5 写明原因。

## 4. 稳定但不承诺的部分

以下内容**会被用到但不在兼容承诺内**，改动时会尽量保留：

| 项 | 说明 |
|---|---|
| `data-map2d-legend` / `data-map2d-coords` / `data-map2d-compass` | 自绘控件的 `data-*` 标记：为自动化测试与宿主定位提供锚点。**会尽量保持**，但极端情况下可能调整（调整时在 §5 记录） |
| CSS 类名前缀 `map2d-map` | 模块样式注入的容器标记类，宿主可用它覆写样式；**保持**，但样式细节（颜色/圆角）可能微调 |
| `map-2d-control-style` | 模块注入的 `<style>` 元素 id，供宿主覆盖。**保持** |
| 事件名 `map2d:tile-precision-change` / `map2d:basemap-change` | 内部广播事件，用于跨组件同步。宿主**不应**依赖，请改用 `basemaps.onChange()` 等公开回调 |
| 图层与数据源 id（`lyr-*` / `src-*`） | 内部约定；宿主请用 `moveLayerGroup` / `setLayerGroupOpacity` 等分组级接口，不要直接 `map.getLayer('lyr-target')` |

## 6. 宿主自查清单（升级模块时）

1. 是否有代码直接 `import` 模块内部路径（`@map2d/src/...`）？→ 有则需改为公开入口；
2. 是否依赖了图层 id / 数据源 id？→ 改为分组级接口；
3. 是否依赖"控件默认显示"？→ 显式 `showControls`；
4. 是否构造了完整的 `DrawSnapshot`？→ 检查 `route` / `shape` 两个新键；
5. 是否监听了 `map2d:*` 内部事件？→ 改为公开回调（`basemaps.onChange` 等）。

以上任意一条命中，升级前请对照本文件 §5 确认影响。
